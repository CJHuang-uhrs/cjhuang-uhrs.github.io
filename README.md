# Chengjun Huang · 黄成君

康复大学黄成君的中英文学术主页。

网站：https://cjhuang-uhrs.github.io/

首页：index.html / en.html。各栏目：research、publications、funding、experience、teaching、service、join；英文页面后缀 -en.html。cv.html 是完整学术简历。

修改对应 HTML 文件后提交，GitHub Pages 自动更新。样式位于 style.css，菜单和论文筛选位于 script.js。头像为 portrait.jpg，谷歌学术图标为 scholar.svg。

本地预览可运行 python3 -m http.server 8765，仅公开网页文件，不包含原始个人材料。
