# Chengjun Huang · 黄成君

中英文学术主页，原生 HTML / CSS / JavaScript，无构建依赖。

## GitHub Pages 发布

1. 使用 CJHuang-uhrs 账户创建公开仓库 `cjhuang-uhrs.github.io`。
2. 将本目录的 index.html、en.html、cv.html、style.css、script.js、assets 文件夹和 .nojekyll 上传至仓库根目录。
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。
4. 等待部署完成，访问 https://cjhuang-uhrs.github.io/ 。

## 本地预览

在本目录运行 `python3 -m http.server 8765`，访问 http://localhost:8765/ 。
